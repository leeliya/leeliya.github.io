Real-time IoT anomaly detection platform

Simulated sensors stream into Kafka. Two Flink jobs flag anomalies with thresholds and compute windowed aggregations. ClickHouse stores raw readings, aggregates and alerts, and Grafana dashboards show it all live. The whole stack runs with Docker Compose.

IoT and computer vision

Smart glasses for visually impaired people

Connected glasses that help in three ways. An ESP32-CAM sends images over Wi-Fi to a Flask server that reads text aloud through a multimodal API, recognises Moroccan banknotes and coins, and warns about obstacles with a spoken direction. An ETL pipeline that reads building models in the IFC format, extracts elements and their properties, transforms them to structured JSON and loads them into SQL. Parsing, extraction, transformation and loading are separate services, and each element's GlobalId is its identity so a re-run updates data instead of duplicating it. Systems, command-line tool

MAPC: a code performance monitor

A command-line tool written in Bash that measures how a program behaves and reports where it is slow. It profiles execution time, memory (with Valgrind) and system calls (with strace), and can run the analysis in forked processes, threads or an isolated subshell. Reports come out as text, HTML, JSON or CSV, and a run can be compared with an earlier one. It has timestamped logging, admin-only options and clear error codes.

BashValgrindstraceLinuxC
